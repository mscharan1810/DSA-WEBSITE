Firebase Realtime Database Rules

To allow your phone and PC to sync without requiring user logins, your Firebase Realtime Database should be set to Test Mode or have public read/write rules:

Firebase Console → Realtime Database → Rules 
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
